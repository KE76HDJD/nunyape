# Guide de Démarrage

## Prérequis
- Node.js 18+
- Base de données MongoDB
- Compte de service cloud

## Installation
1. Cloner le repository
2. `npm install`
3. Configurer les variables d'environnement
4. `npm run dev`

## Premiers Pas
- Créer un compte administrateur
- Configurer les paramètres de base
- Ajouter du contenu
